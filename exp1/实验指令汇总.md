# 实验指令汇总

## 1. 准备

在 `exp1` 目录打开终端，执行：

```bash
conda activate mono_depth
cd Depth-Anything-V2
```

以下命令均在 `Depth-Anything-V2` 下执行。默认使用 NYU 的 8 张图、Small 模型；脚本中的相对文件路径以该仓库为基准。

## 2. 深度预测

```bash
# 相对深度版
python run.py --input-size 280 --pred-only
python run.py --input-size 518 --pred-only

# Metric 版：Hypersim 室内权重，max-depth=20
python metric_depth/run.py --input-size 280 --pred-only
python metric_depth/run.py --input-size 518 --pred-only
```

预测保存到 `outputs/<relative或metric>/<尺寸>/prediction/`，包含原始 NPY、显示 PNG 和 `inference_timing.json`。已有预测时可跳过此步骤。

## 3. 点云生成与评估

```bash
# 相对版：逆深度对齐后评估
python geometry_all.py --input-size 280 518

# Metric：直接评估原始米制深度
python geometry_all_metric.py --input-size 280 518

# Metric：先取倒数，再对齐、评估
python geometry_metric_aligned.py --input-size 280 518
```

只处理一个尺寸时，例如 `--input-size 518`。每组结果写入 `outputs/<模型>/<尺寸>/<aligned或raw>/`，包含深度 NPY、预测/参考点云和 `metrics.csv`；执行后自动刷新汇总表。

单独处理相对版的一张图：

```bash
python geometry.py nyu_0001 --input-size 518
```

## 4. 查看点云

```bash
python view.py --model relative --input-size 518 --protocol aligned --image-id nyu_0001
python view.py --model metric --input-size 518 --protocol raw --image-id nyu_0001
python view.py --model metric --input-size 518 --protocol aligned --image-id nyu_0001
```

查看参考点云时追加 `--kind gt`，默认显示预测点云。

## 5. 汇总结果

```bash
python summarize_results.py
```

- `outputs/summary/all_metrics.csv`：六组逐图明细，完整实验为 48 行。
- `outputs/summary/means.csv`：六组逐图等权均值，完整实验为 6 行。
- 汇总表用 `model`、`input_size`、`protocol` 区分实验组；对齐组含 `alignment_a`、`alignment_b`。

`aligned` 使用真值校正逆深度尺度与偏移，再裁剪到 `[0.1, 10]` 米；`raw` 不对齐、不裁剪。公平几何比较使用两版的 `aligned`；Metric 的 `raw` 用于评价原始绝对距离精度。RMSE 单位为米。

## 6. 自选图片

```bash
python run.py --img-path inputs/classroom.png --outdir outputs/examples/classroom --pred-only
```

自选输入需显式指定 `--outdir`，与 NYU 实验输出分开保存。
