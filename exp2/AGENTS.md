# Exp2 项目约定

- 用户报告风格以 `../exp1/report/` 为准；使用青蓝模板、名词短语标题、自然的学生表述。
- 课程评分与页数以原始 PPTX 第 11 页为准；报告限 5 页，不贴基础知识或程序代码，保留要求的反投影推导。
- 运行说明维护在 `实验指令汇总.md`；配置、路径与 `run.py`、`geometry_all.py` 保持一致。
- `MVSNet/` 保留上游源码；本地适配放在 `mvsnet_local/`，避免 macOS 不区分大小写导致目录冲突。
- 助教权重在 `checkpoints/`，不得误用 GRU 权重或其他网络结构；数据、权重、生成结果、图表和 PDF 只保留在本地，不得提交或强制添加。
- 该数据没有真值，不把置信度、点数和内部几何一致性写成绝对精度。
- 网络输入视图数含参考图；几何检查的源图数量另计。反投影与重投影统一使用半像素中心。
- 正式输出按 `outputs/views{3,5}/{prediction,raw,fusion}` 分组。更改实验设置时使用新输出目录，避免混合结果。
- 更新结果后重建图表、核对正文数值、编译并逐页检查 PDF。
- 临时文件用 `mktemp -d`，完成验证后清理；不创建未获要求的持久备份。
