# 实验2：立体匹配与三维重建

使用课程提供的 DTU scan9 与 BlendedMVS 3DCNNs 权重，完成 MVSNet 深度预测、参数比较和点云重建。报告沿用实验1的青蓝样式与章节结构。

先看 [实验指令汇总](实验指令汇总.md)，报告位于 [report/report.pdf](report/report.pdf)。

下表描述完整的本地工作区。数据、权重、课件、实验输出和生成图表不随 Git 上传；最终报告 PDF 随源码维护。

## 实验设置

两组均采用 1152×864 输入、288×216 深度图、192 个线性深度假设、间隔比例 1.06；每张参考图使用配对文件中评分最高的 2 或 4 张源图。没有额外训练、尺度对齐或深度细化。TensorFlow 2.16.2 CPU 后端直接读取原始 checkpoint，未转换成其他模型。

每组均生成三档置信度阈值下的融合点云，分别为 0.6、0.8、0.95。几何检查使用每张参考图的 10 张候选源图，与网络输入的 2/4 张源图数量区分。至少 2 张源图通过往返像素误差 < 1 px、相对深度误差 < 1% 的检查后，参考像素才能保留。随后做深度平均及 0.5 mm 体素合并。

数据包没有深度真值和参考点云，因此报告不声称绝对精度提高。置信度、点数和往返偏差属于内部统计。全部点云保留原始坐标尺度，单位为 mm。

## 来源与适配

原始代码来自 [YoYo000/MVSNet](https://github.com/YoYo000/MVSNet)，具体提交与源码包哈希见 `MVSNet/UPSTREAM.json`。助教压缩包在 CRC 完整性核对后解压，原 ZIP 已按要求删除；解压文件保留不变。

当前上游权重使用的是带 GN 的 U-Net 特征网络，不能简单换成另一个 PyTorch 项目的八层特征网络。`mvsnet_local/model.py` 保留上游连接结构、卷积填充、GN 分组、2D 反卷积无 ReLU 的设置，以及测试代码采用的当前代价体 BN 统计；使用 TF2 的原始算子替代旧接口。特征按视角缓存，代价体按小批深度片构造。

置信度沿用上游四项概率求和；深度下标恰为整数或处于边界时，索引可能重复。本次正式结果中有 1 个像素明显大于 1（5 视图、参考图 28，值约 1.869），原始数据与统计保留该值，显示图将其画成白色。它是上游计算的边界情况，不能把此置信度严格解释成校准后的正确概率。

`verify_model.py` 在唯一系统临时目录中，与原始完整 `inference` 做对照。对照端只做 Python 3 整数除法、旧 TensorFlow API、已删除的图像变换接口等兼容调整，不改网络拓扑和权重。`outputs/summary/model_parity.json` 记录检查尺寸与误差，验证范围不冒充全数据逐像素一致性证明。

后处理为本地 NumPy/OpenCV 实现，不依赖 CUDA fusibile，也不宣称与其点云逐点一致。相关几何变换和阈值在报告、命令说明与代码中保持一致。

## 复现与文件约定

正式命令见 `实验指令汇总.md`。远端仅保留程序、配置、说明、可编辑的 LaTeX 源码和最终报告 PDF；换机时应另行准备课程数据与权重，再运行实验、生成报告图表并编译。上游目录不含嵌套 `.git`，按普通源码文件管理。实验数据与正式结果保留在本地项目目录并由 Git 忽略；临时编译、数值对照和渲染检查使用系统临时目录并自动清理。
