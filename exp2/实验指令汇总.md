# 实验指令汇总

以下命令均在 `exp2` 目录执行。

## 1. 环境准备

```bash
conda activate mvsnet
```

数据目录：`data/scan9/`；权重目录：`checkpoints/tf_model_blendedmvs/`。

## 2. 深度预测与可视化图生成

### 全部参考视角

```bash
python run.py --views 3
python run.py --views 7
python run.py --views 11
```

输入视图数包含参考图。结果位于 `outputs/views{3,7,11}/prediction/`，同时生成彩色深度图、灰度置信度图和参考原图。

### 指定参考视角

```bash
python run.py --views 7 --ids 12
```

使用 7 视图输入，仅预测参考视角 12。已有结果默认跳过。

### 指定参考视角重新预测

```bash
python run.py --views 7 --ids 12 --overwrite
```

重新计算并覆盖该视角的预测和可视化图。

## 3. 点云生成与参数对比

### 全部实验组

```bash
python geometry_all.py
```

处理 3、7、11 视图组，比较置信度阈值 0.5、0.65、0.8、0.95；原始点云和融合点云分别位于各组的 `raw/`、`fusion/`，融合结果按阈值保存在 `prob_050/`、`prob_065/`、`prob_080/`、`prob_095/`。深度预测保持不变。

### 指定实验组与阈值

```bash
python geometry_all.py --views 7 --prob-threshold 0.8
```

读取 7 视图组全部 49 个参考视角的预测，生成原始点云和阈值 0.8 的融合点云。当前不支持仅生成指定参考视角。

## 4. 点云查看

### 融合点云

```bash
python view.py --views 7 --kind fusion --prob-threshold 0.8
```

显示 7 视图组、阈值 0.8 的融合点云。

### 指定参考视角原始点云

```bash
python view.py --views 7 --kind raw --image-id 12
```

仅显示参考视角 12 的原始点云。

### 全部参考视角原始点云

```bash
python view.py --views 7 --kind raw
```

显示全部参考视角合并后的原始点云。鼠标拖动旋转，滚轮缩放。
