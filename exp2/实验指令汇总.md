# 实验指令汇总

## 1. 准备

远端不含数据、权重和生成结果。新克隆后，先将课程 scan9 数据放到 `data/scan9/`，将课程权重放到 `checkpoints/tf_model_blendedmvs/`，再运行以下命令。

在 `exp2` 目录打开终端，执行：

```bash
conda activate mvsnet
```

本机环境已建好。换到新电脑时，在 `exp2` 下执行 `conda env create -f environment.yml`。以下命令均在 `exp2` 下执行，程序内部的输入输出路径以脚本所在目录为准。

默认使用助教提供的 scan9 全部 49 个参考视角和 BlendedMVS 3DCNNs 权重，输入尺寸为 1152×864，192 个深度采样，间隔比例 1.06。使用 TensorFlow CPU 后端，无需 CUDA。

## 2. 深度预测

```bash
python run.py --views 3
python run.py --views 5
```

3、5 均包含参考图自身，即分别配合 2、4 张源图。结果保存到 `outputs/views3/prediction/` 和 `outputs/views5/prediction/`，包含深度/置信度 PFM、显示 PNG、原始 NPZ 和 `inference_timing.json`。

已有结果默认跳过；需要重新计算时追加 `--overwrite`。仅处理一个参考视角可追加 `--ids 12`。更改默认输入尺寸、深度采样数或间隔时，必须显式指定新的 `--outdir`，避免混入正式结果。

## 3. 点云生成与参数对比

```bash
python geometry_all.py
```

默认处理两组预测，分别比较置信度阈值 0.6、0.8、0.95：

- `outputs/views*/raw/`：49 份直接反投影点云及 `all.ply`。
- `outputs/views*/fusion/prob_060/`、`prob_080/`、`prob_095/`：对应阈值下的 `fused.ply`、逐图掩膜、统计 CSV 和配置。

只处理一组，例如：

```bash
python geometry_all.py --views 5 --prob-threshold 0.8
```

后处理固定往返像素偏差 < 1 px、相对深度差 < 1%，至少 2 张源图一致，再做深度平均和 0.5 mm 体素合并。它是 CPU 多视角融合实现，不是 CUDA fusibile。

## 4. 查看点云

```bash
python view.py --views 5 --kind fusion --prob-threshold 0.8
python view.py --views 5 --kind raw --image-id 12
python view.py --views 5 --kind raw
```

鼠标拖动旋转，滚轮缩放。原始点云包含未过滤的背景点，显示范围通常比融合点云大。

## 5. 汇总结果

```bash
python summarize_results.py
python verify_outputs.py
```

- `outputs/summary/prediction_metrics.csv`：两组逐图预测统计，共 98 行。
- `outputs/summary/prediction_means.csv`：两组均值。
- `outputs/summary/fusion_metrics.csv`：六组逐图过滤统计，共 294 行。
- `outputs/summary/fusion_summary.csv`：六组点云汇总。

置信度、点数与重投影偏差仅用于观察本组数据的一致性，不能代替有真实参考值的精度评估。

## 6. 实验报告

```bash
python report/prepare_results.py
bash report/build.sh main.tex report.pdf
```

报告为 `report/report.pdf`，源文件入口为 `report/main.tex`。图表读取已有实验结果，不重新运行模型；重新实验后，正文中的分析数值也应同步核对。编译需要 XeLaTeX 与 latexmk，辅助文件自动放入系统临时目录并清理。

可选的程序核对：

```bash
python verify_model.py
python verify_geometry.py
```

分别核对适配程序与上游推理结果，以及已知平面的反投影、重投影与过滤行为。
