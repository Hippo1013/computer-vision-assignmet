## 实验方案

五组均使用完整的官方50000张训练图训练，每轮用官方10000张测试图计算损失和准确率。不划分验证集，不增加最终重训。

| 作业步骤 | 实验内容 | 结果复用 |
|---|---|---|
| 第一步：基线复现 | ResNet10、SGD、固定学习率0.001 | 作为第二、三步的基线 |
| 第二步：优化器比较 | SGD与Adam，均固定学习率0.001 | SGD复用第一步，只新增Adam一组 |
| 第三步：SGD学习率分析 | 固定0.001/0.01/0.1，以及初始0.1、完成第30/40轮后分别降10倍 | 固定0.001复用第一步，新增其余三组 |

`stage1.json` 按上述顺序定义五组，各50轮，共250轮。固定种子20261029；相同初始权重和每轮数据顺序、增强随机种子。SGD动量0.9；两种优化器权重衰减0.0001；Adam betas=(0.9,0.999)、eps=1e-8。Adam只测0.001。

沿用课程代码的ResNet10、小卷积入口、三次下采样和数据增强/归一化。FP32，关闭TF32，cuDNN确定性模式。正式五组统一batch=1280、workers=0。训练和测试图片以uint8一次性常驻GPU，每批在GPU上逐张采样水平翻转、零填充裁剪并转FP32归一化，保持原增强规则。容量试跑以Adam检查显存，选择独立显存预算内、吞吐接近最快且批量较大的配置。`stage1.json`中的256是容量试跑起点，实际值记录在`protocol.json`的`common.batch_size`及各组`config.json`。

保留原始入口`cv_homework2/resnet-cifar100.py`；新增`train_stage1.py`复用其模型定义，增加配置、完整指标、日志和断点恢复，评估方式与原脚本一致使用测试集。
