# 实验3报告

采用青蓝实验报告模板及 XeLaTeX。当前已完成实验要求第一点“图像灰度化与灰度直方图”、第二点“HOG特征可视化与参数分析”、第三点“HOG算法流程与特征维度”、第四点“CIFAR-10图像分类与参数影响”和第五点“交通标志图像分类与参数影响”。

整份报告共5页，采用连续排版，已完成逐页渲染检查。第四、第五部分各新增一个分类正确和一个分类错误的测试样本，展示原图、真实类别及中文模型预测类别。第五部分包含“分类结果与特征维度”“HOG参数影响分析”“分类样本对比”，使用结果表和文字分析比较六组完成实验，按用户最新要求不展示参数影响图。第三部分保留简明算法流程、关键公式和实测对照，不展示示意图。

课程统一要求为“写明完成过程、结果分析等，不要贴基础知识和代码，≤5页”。正文不贴代码；第三点按题目要求保留简明原理、维度推导和实测对照。所有内容合并后的最终报告不得超过5页。

## 文件说明

- `main.tex`：报告入口与作者信息。
- `grayscale.tex`：第一点的过程、结果与分析。
- `hog-visualization.tex`：第二点的实验设置、方向数全图与局部可视化、Cell大小可视化和归一化前直方图、Block大小组归一化后Cell直方图，以及特征维度比较。
- `hog-dimension.tex`：第三点的简明算法流程、维度推导和实测对照，当前不包含示意图。
- `hog-principles.tex`：原边缘与梯度、Cell方向统计、Block组合示意图源码，当前不被报告入口引用；既有素材保留。
- `cifar-classification.tex`：第四点的最佳组合、分类结果、3,600维计算，方向数、Cell与Block配合关系的分析，以及正确/错误样本对比。
- `traffic-classification.tex`：第五点的交通标志分类结果、404,496维计算、结果表、文字分析及正确/错误样本对比，当前不引用参数影响图。
- `qinglan-report.sty`：青蓝模板样式。
- `prepare_results.py`：核验已有灰度图，准备报告图片和统计结果；不运行 HOG 或分类实验。
- `prepare_hog_comparison.py`：从已完成的7组HOG实验读取完整特征、可视化和直方图，核验哈希与维度并准备三类参数对比图；不重新提取特征或训练分类器。
- `prepare_classification_results.py`：只读已有CIFAR-10分类与调参结果，生成第四点的三联趋势图、分类结果表及素材元数据；不运行特征提取或训练。
- `cifar-classification-table.tex`：由上述脚本生成的本地分类结果表，不提交远端。
- `prepare_traffic_results.py`：只读六组已完成的交通标志实验，核验模型和预测哈希、重算准确率及维度，生成第五部分表格、参数影响三联图和素材元数据；不提取特征或训练。
- `traffic-classification-table.tex`：第五部分自动生成的本地分类结果表，不提交远端。
- `prepare_prediction_examples.py`：只读两组最佳模型及保存的测试预测，导出四张样本图，重新提取这四张图的HOG并重放模型预测，生成样本映射及哈希元数据；不训练模型。
- `figures/`：本地报告素材及统计结果，不提交远端。
- `实验3-基于传统视觉的图像分类.pdf`：最终报告。

```bash
rm -rf "$REPORT_TMP"
/Users/hippo/miniconda3/envs/svm_classifier/bin/python ../cv_homework1/verify_hog_dimension.py
bash build.sh main.tex 实验3-基于传统视觉的图像分类.pdf
```

输入为 `../cv_homework1/jinx.jpg` 及用户程序已保存的 `../cv_homework1/outputs/grayscale/jinx_gray.png`。报告直方图由已有灰度图重绘，采用原程序相同的256个灰度级计数口径。原始三联图保留在 `../cv_homework1/outputs/grayscale/grayscale_histogram.png`。

构建脚本使用系统临时目录存放 LaTeX 中间文件，完成后自动清理。最终 PDF 还需逐页渲染检查。

第三点使用原始 `jinx.jpg` 的灰度图，以 `orientations=9`、`pixels_per_cell=(8,8)`、`cells_per_block=(16,16)` 调用 HOG。实测未展开数组形状为 `(39,81,16,16,9)`，一维特征长度为 `7278336`，与推导一致；两种返回形式展开后逐项相同。记录位于 `../cv_homework1/outputs/hog_dimension/verification.json`，不保存完整特征数组。
